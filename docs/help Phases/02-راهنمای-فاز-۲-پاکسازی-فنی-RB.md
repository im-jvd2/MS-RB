### T-030 — اسکیمای Service + FAQ + Breadcrumb ✅ — انجام شد ۱۱ Oct 2026 (WPCode PHP با urldecode+strpos روی ۷ URL، validator ۴ آیتم بدون خطا)

**خروجی:** `اسکیمای هر لندینگ` — **معیار پذیرش:** ۱۰۰٪ لندینگ‌ها اسکیمای معتبر دارند — محقق شد: `validator.schema.org` روی هر ۷ لندینگ `0 ERRORS 0 WARNINGS 4 ITEMS (Organization/LocalBusiness + Article + Service + FAQPage)`

**گام‌های دقیق (زبان ساده):**

1. اسنیپت قدیمی `Service+FAQ+Breadcrumb - 7 Services (id 3442)` را غیرفعال و حذف کنید و تمام ویجت‌های HTML المنتور را از ۷ برگه پاک کنید (تزریق المنتور ناقص می‌ماند).
2. اسنیپت جدید `RB T-030 Service+FAQ - 7 Services` از نوع **PHP Snippet** بسازید — `Auto Insert → Run Everywhere`، `Priority 10`، `Active` — با کد `urldecode(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH))` و ۷ شاخه `strpos('/services/{slug}/')` هر کدام دو `echo '<script type="application/ld+json">'` جدا (یکی Service و یکی FAQPage).
3. `LiteSpeed Cache → Purge All` بزنید و در `validator.schema.org → Fetch URL` هر ۷ URL را تست کنید — باید `Service 1 ITEM 0 ERRORS` و `FAQPage 1 ITEM 0 ERRORS` دیده شود (Rich Results همچنان ۴ می‌ماند چون FAQ دیگر Rich Result نیست).

**ارسال شواهد:** اسکرین‌شات `validator.schema.org` با ۴ آیتم ۰ خطا (۱۱ Oct 13:40) — **بدون رمز**.
