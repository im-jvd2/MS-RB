## قرارداد نام‌گذاری گزارش‌ها

```
docs/reports/{شماره}-گزارش-فاز-{n}-{عنوان کوتاه}-{YYYY-MM-DD}.md
```

* `00` → فاز ۰، `10` → فاز ۱، `20` → فاز ۲، ... `80` → فاز ۸ (ده‌دهی برای مرتب‌سازی)
* هر گزارش شامل: **خلاصه مدیریتی، جدول وضعیت، کارهای انجام‌شده/باقی‌مانده با تاریخ، تصمیم دروازه، اقدامات فوری**
* گزارش‌های میانی (حین فاز) تاریخ‌دار هستند؛ گزارش نهایی بعد از Gate به‌روزرسانی می‌شود.
