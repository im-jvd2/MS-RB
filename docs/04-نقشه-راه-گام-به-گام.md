## ۲) فاز ۱ — رفع انسداد ایندکس سایت خدماتی (هفته ۱) 🚨 — ✅ **انجام شد ۲۱ Sept — G1 عبور ۱۱/۱۱**

**این فاز، بحرانی‌ترین بخش کل پروژه است. تا این حل نشود، فازهای بعد اتلاف منبع‌اند.**

### گام‌ها

| گام | کار | جزئیات دقیق |
|---|---|---|
| ۱.۱ | پراپرتی Domain در GSC + ارسال `sitemap_index.xml` | در بخش Sitemaps، هر سه ساب‌سایت‌مپ RB ثبت شود |
| ۱.۲ | تست `URL Inspection` روی ۱۰ URL | خانه، `/services/`، ۷ لندینگ خدمت، `/contact-us/`. وضعیت هر کدام ثبت شود (Indexed / Crawled-not-indexed / Discovered / Blocked) |
| ۱.۳ | **تست دسترسی Googlebot** | از پنل سرور یا ابزار، با یوزر‌ایجنت `Googlebot` درخواست بزنید و پاسخ را ببینید. اگر ۴۰۳/۴۰۵/چالش گرفت، مسئله WAF است |
| ۱.۴ | **بررسی لاگ سرور** | تایید کنید Googlebot در ۳۰ روز گذشته **آمده** است یا نه؛ اگر آمده، کدام کد پاسخ گرفته (۲۰۰/۳۰۱/۴۰۳/۴۰۵/۵۰۳) |
| ۱.۵ | **بررسی Cloudflare / فایروال** | موارد مشکوک: `Bot Fight Mode` روشن، `Security Level = High`، `Under Attack Mode`، قوانین WAF، چالش JS. **راه‌حل: Verified Bots گوگل allowlist شود** و Bot Fight Mode برای مسیر `wp-content`/کل دامنه خاموش یا تنظیم شود |
| ۱.۶ | تست رندر | `Fetch and Render` / URL Inspection → Live Test → View Rendered HTML. مطمئن شوید محتوا و لینک‌ها در خروجی رندرشده‌ی گوگل وجود دارد (سایت Elementor است، پس این تست حیاتی است) |
| ۱.۷ | بررسی `X-Robots-Tag` و متا ربات‌ها | هیچ صفحه‌ی کلیدی `noindex` نباشد (با Screaming Frog یا افزونه سئو چک شود) |
| ۱.۸ | درخواست ایندکس دستی | برای ۱۰ URL اصلی `Request Indexing` بزنید (سهمیه روزانه محدود است، همه در یک روز نزنید) |
| ۱.۹ | پایش ۷ روزه | هر روز تعداد صفحات ایندکس‌شده در GSC ثبت شود |
| ۱.۱۰ | **دروازه‌ی G1** | عبور = حداقل **۸ از ۱۰** URL در وضعیت Indexed یا «در صف ایندکس». عدم عبور = توقف فاز ۵ و جلسه‌ی فنی با هاست/کلودفلر |

### 🚧 دروازه‌ی G1
| معیار | حد عبور |
|---|---|
| صفحات ایندکس‌شده‌ی RB | ≥ ۸ از ۱۰ URL کلیدی |
| دسترسی Googlebot | ۲۰۰ روی همه‌ی URLهای کلیدی |
| **در صورت عدم عبور** | توقف لینک‌سازی؛ تمرکز کامل روی رفع مانع خزش با هاست/شبکه |

### KPI فاز
گزارش یک‌صفحه‌ای «وضعیت ایندکس رویال برند» با تصویر GSC.

### 📋 فرم بریف نمونه‌کار (خروجی: کارت نمونه‌کار)

برای هر پروژه‌ی قبلی، این ۱۰ قلم را از کارفرما بگیرید؛ بدون این‌ها صفحه‌ی نمونه‌کار ساخته **نمی‌شود** (و تا آن زمان noindex می‌ماند):

1. **نام برند/کسب‌وکار** (و آدرس سایت اگر دارد)
2. **صنعت** (پزشکی، ساختمانی، مامایی، لوکس، آموزشی، صنعتی…)
3. **وضعیت قبل از همکاری** (یک پاراگراف: چه مشکلی داشت)

6. **بازه‌ی زمانی** (شروع و پایان)
7. **نتیجه‌ی عددی** — حداقل دو عدد (مثال: رشد ۲.۱ برابری لید در ۹۰ روز، ROAS ۴.۳، نرخ تبدیل از ۱.۲٪ به ۳.۵٪)

9. **جمله‌ی رضایت مشتری** (۱ جمله‌ی نقل‌قول‌شده با نام و سِمَت)
10. **اجازه‌ی انتشار** (تایید کتبی/چت که برند اجازه‌ی انتشار داده)
